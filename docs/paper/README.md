# Execution Complexity Signatures

**Predicting Autonomous Coding Task Success from Early-Phase Behavioral Patterns**

Analysis of 208 autonomous coding task executions across 12 projects, achieving 93.5% AUC for predicting task success from planning-phase signals.

[Read the paper (PDF)](./execution-complexity-signatures.pdf)

## Citation

Straughter Guthrie. "Execution Complexity Signatures: Predicting Autonomous Coding Task Success from Early-Phase Behavioral Patterns." Viable Systems Research, 2026.

## Source

This paper was generated using [Denario](https://github.com/jmanhype/Denario) with execution data collected from real [wreckit](https://github.com/jmanhype/wreckit) runs across 12 projects.
